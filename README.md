**SUNWARD ISLES** — an original 3D flight game built with Three.js. Fly over
an archipelago generated from a seed (a main island with a full runway plus a
smaller island with a short strip) in three missions: a six-ring circuit, an
island hop ending in a short-runway landing, and a storm mail flight with
gusts and a fuel limit. Chase and cockpit views, six lit instruments, a HUD
with altitude, speed and heading, a stall / fuel / damage flight model, and
synthesized WebAudio sound. The game is static files only: it plays offline
in a desktop browser with keyboard and mouse, with no network request.

## Run it

```sh
node serve.ts   # serves game/ at http://localhost:8080 — open it and fly
node main.ts    # writes the hand-in (game/, screenshots/, dossier.json) to /output
```
